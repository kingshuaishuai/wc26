## Data dictionary — `fixtures_predictions.csv`

- `group` — group letter A–L
- `match_no` — official FIFA match number
- `date` / `time_local` — kickoff (local venue time)
- `venue` — stadium
- `home` / `away` — teams
- `pred_score` — AI predicted scoreline (e.g. `2-1`)
- `home_win_prob` / `draw_prob` / `away_win_prob` — probabilities (sum to 1)
- `key_player` — player to watch
- `ai_analysis` — short written preview
